# WordPress.org Listing Assets

Store plugin directory assets for the public WordPress.org listing here.

Recommended files:

* `icon-128x128.png`
* `icon-256x256.png`
* `banner-772x250.png`
* `banner-1544x500.png`
* `screenshot-1.png`
* `screenshot-2.png`
* `screenshot-3.png`
* `screenshot-4.png`

These files are deployed to the WordPress.org SVN `assets/` directory by the release workflow.
They are not bundled into the installable plugin zip.
