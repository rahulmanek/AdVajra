Modern ads management for WordPress with placements, targeting, tracking, analytics, and a React-powered admin UI.

== Description ==

AdVajra helps you create, organize, place, and measure ads across your WordPress site from a modern admin interface.

Core features in the free plugin include:

* Ad placements for common site locations and injected content positions.
* Custom ad groups and placement management.
* Built-in targeting controls for post type, category, user role, and device.
* Click and impression tracking with lightweight aggregation.
* Privacy-aware tracking hooks and settings.
* A React-powered dashboard for managing ads, placements, analytics, and settings.

AdVajra PRO remains a separate add-on and is not bundled with this plugin.

== Installation ==

1. Upload the `advajra` folder to the `/wp-content/plugins/` directory, or install the plugin through the WordPress plugins screen.
2. Activate the plugin through the `Plugins` screen in WordPress.
3. Open the `AdVajra` admin menu to create your first ad, group, and placement.
4. Review your placement settings and analytics preferences before going live.

== FAQ ==

= Does this plugin include AdVajra PRO? =

No. AdVajra PRO is a separate add-on and is not included in the free release package.

= Will AdVajra work without PRO installed? =

Yes. The free plugin works on its own. PRO features stay locked unless the separate PRO add-on is installed and active.

= Does AdVajra track impressions and clicks? =

Yes. The free plugin includes built-in click and impression tracking with a limited retention window.

= Can I target ads by content type or user role? =

Yes. The free plugin includes targeting controls for post type, category, user role, and device.

= Where do I add ads after activation? =

Open the `AdVajra` menu in the WordPress admin to manage ads, placements, modules, analytics, and settings.
